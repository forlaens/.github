# Support

- For bugs and feature requests, use the relevant repository's issue tracker.
- For setup and usage questions, check the repository README and existing issues first.
- For security vulnerabilities, follow the [security policy](SECURITY.md) instead of opening a public issue.
- For commercial accessibility work, training or collaboration, email [tobias@forlaens.com](mailto:tobias@forlaens.com).

Open source support is provided on a best-effort basis.
