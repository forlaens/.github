# Forlæns GitHub organization files

This repository contains shared GitHub configuration and community files for the [Forlæns organization](https://github.com/forlaens).

- `profile/README.md` is displayed on the organization profile.
- `.github/ISSUE_TEMPLATE/` provides shared issue forms.
- The files in the repository root provide default contribution, support, security, conduct, and pull request guidance for Forlæns repositories that do not define their own.
- `templates/AGENTS.md` provides the local-development and Actions cost policy for new repositories. Commit it as the target repository's root `AGENTS.md`, preserve project-specific guidance and add verified setup and test commands. AGENTS.md is not automatically inherited from this organization repository.

Changes here may affect multiple repositories across the organization.
