# Security Policy

Please do not report security vulnerabilities in a public issue.

Use the repository's **Security** tab to submit a private vulnerability report. If private reporting is unavailable, email [tobias@forlaens.com](mailto:tobias@forlaens.com).

Include the affected repository and version, steps to reproduce the issue, its potential impact, and any suggested mitigation. We aim to acknowledge reports within five business days.

Please allow reasonable time for investigation and remediation before public disclosure.
